    Backup

    Lädt eine ZIP-Datei mit allen Daten als JSON sowie allen Kartenbildern herunter (genaue Liste, was enthalten ist). Zusätzlich wird automatisch einmal pro Woche ein Backup im Hintergrund erstellt und in Supabase Storage abgelegt (die letzten 4 Wochen werden aufbewahrt).

    Backup wiederherstellen

    Spielt eine zuvor heruntergeladene Backup-ZIP wieder ein. Bestehende Zeilen werden anhand ihrer ID aktualisiert, neue eingefügt – nichts wird vorher gelöscht (kein Wipe-and-Replace). Google- Sheets-Verbindung und SMTP-Passwort sind nie Teil eines Backups und müssen nach einer Wiederherstellung auf einem neuen Supabase-Projekt separat neu eingerichtet werden.

    Mindestbestand

    Ab welcher Menge eine Karte im Inventar als "niedriger Bestand" markiert wird (0 = deaktiviert). Gilt global für alle Karten.

    Preis-Alarm

    Ab welcher prozentualen Abweichung des Angebotspreises vom Preisrecherche-Marktdurchschnitt ein Preis-Alarm ausgelöst wird (Kartenseite, eBay-Übersicht, Dashboard-Kachel „Preis-Alarme"). Wirkt in beide Richtungen (zu teuer wie zu billig).

    Anzeige

    Gilt global für alle Tabellenseiten (Karten, Käufe, Inventar, eBay, Inventur, Wunschliste, Statistik-Listen).

    Absenderadresse

    Wird auf dem druckbaren Adress-Etikett/Lieferschein als Absender verwendet (Versand-Checkliste).

    E-Mail-Benachrichtigungen

    Verschickt eine zusammenfassende E-Mail, sobald der automatische Hintergrund-Sync (alle 15 Minuten) neue eBay-Verkäufe findet. Das gespeicherte Passwort wird aus Sicherheitsgründen nie angezeigt – das Feld leer lassen, um ein bereits gespeichertes Passwort beizubehalten.

    Wiedervorlage-Schwellenwerte

    Steuert, ab wann die beiden automatisch erkannten Situationen im Dashboard unter „Was jetzt tun?" (und in der täglichen Erinnerungs-E-Mail) erscheinen.

    Kleinunternehmer-Schwellenwerte

    Umsatzgrenzen der Kleinunternehmerregelung (§19 UStG) für die Warnung auf dem Dashboard und die Kleinunternehmer-Seite – Vorbelegung mit den aktuell gültigen gesetzlichen Werten, hier anpassbar, falls sich diese künftig ändern.

    Push-Benachrichtigungen

    Zusätzlich zur E-Mail: eine Browser-Benachrichtigung auf diesem Gerät, sobald neue eBay-Verkäufe gefunden werden (gleicher Schalter "Bei neuen eBay-Verkäufen benachrichtigen" oben). Auf dem Handy funktioniert das auch bei geschlossener App, wenn die Seite zuvor über "Zum Startbildschirm hinzufügen" installiert wurde (iOS ab Version 16.4, Android ohne Einschränkung).

    Automatisches Re-Listing

    Beendet ein lange unverkauftes eBay-Angebot und veröffentlicht es sofort wieder neu (frisches Listing, relevant für die Sichtbarkeit). Wirkt nur für Angebote, bei denen zusätzlich auf der Kartenseite ("Automatisch neu einstellen nach") eine Tagesanzahl eingetragen ist – dieser globale Schalter ist die zusätzliche Sicherheitsbremse, damit die Automation nicht unbemerkt aktiv wird.

    Angebots-Textbausteine

    Wiederverwendbare Textbausteine für eBay-Beschreibungen (z. B. ein Hinweis für eine ganze Kartenserie) – lassen sich beim Anlegen eines Angebots (einzeln auf der Kartenseite oder per Massenaktion auf der Kartenübersicht) optional in die automatisch generierte Beschreibung einfügen, statt denselben Text bei jeder ähnlichen Karte neu zu tippen.
